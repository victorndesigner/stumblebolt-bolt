Política de Privacidade

Esta política descreve como o Stumble Bolt coleta e utiliza os dados necessários para operar seus recursos de automação, validação e suporte ao fluxo de boosters no Discord.

1. Dados coletados

Podemos processar identificadores como ID do usuário, ID da guilda, cargos, presença/status, conteúdo de mensagem necessário para detecção de boosts e metadados relacionados às chaves e permissões usadas pelo sistema.

2. Finalidade do uso

Os dados são usados para identificar membros, validar acesso, responder interações no Discord, executar fluxos de booster e manter as automações do servidor funcionando corretamente.

3. Compartilhamento

Não vendemos dados pessoais. O processamento acontece apenas quando necessário para o serviço e para integrações técnicas do próprio Discord ou do ecossistema Bolt Texturas.

4. Armazenamento

Os dados podem ficar armazenados em infraestrutura própria do projeto para funcionamento operacional, auditoria técnica e continuidade do serviço.

5. Contato

Dúvidas sobre privacidade e uso de dados podem ser tratadas com o responsável operacional da Bolt Texturas.
